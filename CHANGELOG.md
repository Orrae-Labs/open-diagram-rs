# Changelog

## 0.1.0

Not tagged yet. Fixes land on `main`. This is the first crates.io release of the Rust tree.

- `open-diagram` measures every label from the bundled Inter fonts and writes a deterministic SVG.
- `open-diagram-cli` is the `open-diagram` command. It reads JSON and Mermaid.
- `open-diagram-mcp` is the stdio MCP server. Its tools are `format_guide`, `template`, `check`, `describe`, and `draw`.
